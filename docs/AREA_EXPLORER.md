# Public reference site

The public pages are the homepage, Field Guides, School & Program Library, individual field/program guides, and Compare Programs. Job-example pages and the retired legacy/preference HTML interfaces were removed on 2026-10-21. Career descriptions and competencies remain in all field guides; the database and career/posting exports are unchanged.

- `site/area-article.js` renders all 18 field guides, including careers and study routes.
- `site/program-article.js` links each library program to the guides named by `primaryFields` and to its comparison row.
- `site/compare.html` is static HTML generated by `scripts/build_program_comparison.py`. It contains every current library program and works without JavaScript.
- Comparison cards show program focus, concrete animal experience, three study examples and two planning considerations. Reviewed summaries and their source URLs are maintained in `site/content/programs/comparison-notes.json`; review dates remain backend metadata.
- Shared `site/areas.css` provides keyboard focus, skip links, dark-mode reading surfaces and sticky desktop article TOCs. On phones and tablets, the comparison reflows into labelled cards without horizontal scrolling.

Rebuild and inspect changes:

```sh
python3 scripts/areas_build.py site/content/areas
python3 scripts/build_program_comparison.py
git diff -- site/content/areas site/compare.html
python3 scripts/validate_public_site.py
```

No career research data should be removed as part of presentation changes.
