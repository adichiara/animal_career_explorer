How to read this table

Required animal contact has three values. Built into the program means the record documents required hands-on animal work. Depends on choices means it is available but set by electives, internships, or placements. Not established in the record means the official sources reviewed do not establish a required animal-contact component — it does not mean the program has none. Field research, observation, clinical practice, and direct animal care are different kinds of experience; check the program page for which applies.

Documented emphasis groups the stronger preparation areas described in each program guide. These summarize the existing curriculum review. They are not standardized ratings, guarantees, or rankings, and the number of areas shown partly reflects how much detail each record carries. Electives, concentrations, minors, and certificates determine much of what a student actually studies.

Sources and verification notes for each program are on its own page.
